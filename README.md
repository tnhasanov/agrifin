# AgriFin — prototip

Fermerlər üçün ağıllı maliyyə tətbiqi: peyk əsaslı tövsiyələr, məhsul dövrü kreditləri,
kart və pulqabı, bazar qiymətləri və karbon gəliri.

**Demo prototipdir — bütün məlumatlar nümunədir.**

## Necə işə salmalı (lokal, istəyə bağlı)

```bash
npm install
npm run dev
```

## Deploy

Bu repo Vercel və ya Netlify-a qoşulduqda avtomatik build olunur (Vite + React).
